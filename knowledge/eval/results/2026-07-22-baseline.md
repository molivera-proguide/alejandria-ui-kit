## Judge-calibration note (important)

G2 was scored **21 live, corrected to 22** on review: the live judge docked Tonality for using `Button variant="pdf"` (grey) on the login, preferring console teal. That was wrong — `anti-examples.md` §2/§5 and `design-language.md` establish Login/Fichas/Modal as **PDF-context screens** where grey `pdf` is the *correct* palette and teal would be the error. The agent followed the documented rule. **Lesson: the judge must consult `anti-examples.md` §5 before scoring Tonality on login/ficha/modal screens.** The rubric's "cite the specific rule" instruction exists for exactly this.

## Findings → fixes (input to loop step 4)

- **[THEME — highest impact] Component sizing (÷2 → fluid).** G1 (kanban `TaskCard` sit ≤140px in wide columns → empty space), G4 (ficha `MetricCard` stretch full-width + `LineChartCard` fills viewport), G5 (`Asistente` frozen at 774px @2×). Compact/PDF-scale components either have no width cap (stretch) or are fixed in px (don't adapt). → (component) responsive rework of the @2× fixed sizes + sensible `max-*` defaults on charts/ficha metrics; (knowledge) new anti-example pair on constraining compact components. **New `anti-examples.md` §7.**
- **[knowledge, cheap] Type tokens on hand-rolled headings.** G1 hardcoded `fontWeight:700` / `letterSpacing:0.04em` on the page title where `--ds-font-weight-bold` / `--ds-tracking-tight` exist (AP12). G4 avoided it by using `Card`'s title prop. → **New `anti-examples.md` §8.**
- **[a11y / fidelity tension] Ficha metric labels low-contrast.** G4: ficha label is spec-faithful (extralight + `--ds-color-pdf-ink-muted`) but barely legible on dark. This is a real accessibility limitation, NOT a generation defect (the render is correct per spec). Track as an a11y-vs-fidelity item, not an anti-example. → `component-roadmap.md`.
- **[coverage — confirmed by real consumer need] `Pagination` + `DataTable` sort/filter/paginate (G3), `Modal`/`Dialog` (G6).** Both hit immediately by realistic tasks; the agent correctly reported them rather than inventing. → `component-roadmap.md` high priority.
